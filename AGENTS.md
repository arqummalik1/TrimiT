# Repository Rules

These rules apply to the entire repository:

1. Never assume anything. If information is missing or ambiguous, inspect the relevant source or ask the user.
2. Always check the code and verify the facts before making a claim or taking action.
3. Never push code unless the user explicitly asks for it.
4. Before changing or reviewing this production system, read
   `docs/STRICT_ENGINEERING_RULES.md` completely and follow it. This is mandatory
   for every human or AI agent working anywhere in this repository.
